# Fitopia Coach Panel (PWA)

پنل اختصاصی مربیان فیتوپیا — React 19 + Vite + TypeScript + Tailwind v4 + PWA

## اجرا محلی
```bash
npm install && npm run dev
# http://localhost:5174/welcome
```

## Docker
```bash
docker compose up -d --build
# http://SERVER:8081
```
